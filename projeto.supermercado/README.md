# 🛒 Mercado Digital Acessível (60+)
> Projeto desenvolvido no curso Técnico em Desenvolvimento de Sistemas para a disciplina de Projetos de Software (Metodologia Scrum - 20h).

---

## 📌 Visão do Produto

* **Tema:** Mercado Digital / E-commerce Acessível
* **Problema:** Pessoas idosas (60+) enfrentam dificuldades em e-commerces tradicionais devido a textos pequenos, excesso de banners, poluição visual e fluxos de checkout confusos que causam erros e desistências.
* **Público-Alvo:** Idosos (60+ anos) com pouca familiaridade digital, limitações visuais e/ou motoras leves.
* **Objetivo do MVP:** Desenvolver uma interface de mercado ultra-simplificada, focada em alta legibilidade, botões gigantes, categorias claras e um fluxo de compra direta em 3 passos.

## 🗺️ Sitemap (Estrutura do MVP)

1. **Home / Catálogo:** Busca em destaque, categorias visíveis em cards grandes e botões visíveis de inclusão no carrinho.
2. **Sacola de Compras:** Lista limpa de produtos selecionados, ajuste de quantidade (`+` / `-`) e valor total em destaque gigante.
3. **Checkout / Confirmação:** Formulário simplificado de entrega e pagamento com poucas etapas.
